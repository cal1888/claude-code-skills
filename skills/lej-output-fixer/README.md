# LEJ Output Fixer

Three ready-made Claude Code output styles (including 'Bottom Line First') plus a picker command — makes Claude's replies readable again.

- **Author:** justfinethanku ([`justfinethanku/LEJ-output-fixer`](https://github.com/justfinethanku/LEJ-output-fixer))
- **License:** MIT
- **Status:** 🔗 Install-linked — this skill is **not** rehosted here; install it from the official source below.

## Install

```bash
claude plugin marketplace add justfinethanku/LEJ-output-fixer
claude plugin install lej-output-fixer@lej
```

## Why install-linked and not vendored?

A plugin (output styles + a `/style` picker command), not a bare skill folder, so it is linked rather than copied. Works in the terminal and the desktop app.
