# Interfaces

Eleven 'better-*' skills for building great interfaces — layout, typography, colour, accessibility, UX writing, reviews, variants.

- **Author:** Jakub Krehel ([`jakubkrehel/skills`](https://github.com/jakubkrehel/skills))
- **License:** MIT (included in [`LICENSE`](LICENSE))
- **Status:** ✅ Vendored from [`jakubkrehel/skills`](https://github.com/jakubkrehel/skills); original `LICENSE` included

## Files

- `skills/better-accessibility`, `better-colors`, `better-interface`, `better-layout`, `better-typography`, `better-ui`, `better-writing`, `break`, `explain-interface`, `interface-review`, `variant`

## Install

```bash
cp -r skills/interfaces/skills/* ~/.claude/skills/

# Or as a plugin from source (recommended — keeps it updated)
claude plugin marketplace add jakubkrehel/skills
claude plugin install interfaces@interfaces
```
