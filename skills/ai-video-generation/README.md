# AI Video Generation

**Generate video across 40+ AI models via [inference.sh](https://inference.sh).**

Command-line access to 40+ AI video models — Google Veo, ByteDance Seedance, Alibaba Wan, Grok Imagine Video, OmniHuman and more. Supports text-to-video, image-to-video, avatar animation, lipsync, video upscaling and foley sound generation.

```bash

```

Requires the inference.sh CLI (`npx skills add inference-sh/skills@infsh-cli`) and an inference.sh account/API key.
