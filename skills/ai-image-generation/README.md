# AI Image Generation

**Generate images across 50+ AI models via [inference.sh](https://inference.sh).**

Command-line access to 50+ AI image models — FLUX, Gemini, Grok, Seedream, Reve and more. Supports text-to-image, image-to-image, inpainting, LoRA, image editing, upscaling and text rendering. Good for social graphics, illustrations, product images and other visual content.

## Install

```bash
npx skills add inference-sh/skills@ai-image-generation
```

Requires the inference.sh CLI (`npx skills add inference-sh/skills@infsh-cli`) and an inference.sh account/API key.
