# ASO & App Marketing Skills

40-skill pack for App Store Optimization and app marketing — audits, keyword research, metadata, screenshots, reviews, launches, Apple Search Ads, localization, retention, monetization.

- **Author:** Eren Can Arıca / Appeeky ([`Eronred/aso-skills`](https://github.com/Eronred/aso-skills))
- **License:** MIT (included in [`LICENSE`](LICENSE))
- **Status:** ✅ Vendored from [`Eronred/aso-skills`](https://github.com/Eronred/aso-skills); original `LICENSE` included

## Files

- `skills/` — 40 skill folders; start with `app-marketing-context` (the foundation every other skill reads first), then `aso-audit` / `keyword-research`

## Install

```bash
cp -r skills/aso-skills/skills/* ~/.claude/skills/

# Or from source (recommended — the pack grows often)
npx skills add Eronred/aso-skills
```

## Notes

Several data-driven skills pull live App Store data via the [Appeeky API](https://docs.appeeky.com) (`asc-metrics`, keyword and competitor tools); the strategy and copywriting skills work without it. Snapshot taken September 2026.
